# Custo de IA

Consultado em 2026-10-19. Preços em `data/pricing.csv` (Anthropic, OpenAI, Gemini). Reabra antes de afirmar: preço de modelo muda com frequência, e a página do Gemini já anunciava aumento com data.

## Conta por chamada
custo = tokens de entrada x preço de entrada + tokens de saída x preço de saída + leitura de cache x preço de leitura + escrita de cache x preço de escrita.

Por usuário: chamadas por usuário no mês x custo por chamada. Total: x MAU. Monte com faixa:
```bash
python3 scripts/estimate.py --plan "Anthropic API=Claude Sonnet 5.5" --use input_mtok=5-20 --use output_mtok=1-4 --use cache_read_mtok=0 --use mau=1000-5000
```
Para descobrir tokens: o console da API mostra uso por dia; no código, o tamanho do prompt fixo (sistema, exemplos, ferramentas) é o que mais pesa.

## Alavancas, em ordem
1. **Teto de gasto** no console [IA-LIMITE]. Antes de qualquer otimização. Sem ele, um loop ou chave vazada vira conta sem limite.
2. **Prompt caching** [IA-CACHE]. Vale quando há trecho longo repetido (instrução de sistema, documento, ferramentas). Na Anthropic marca-se com `cache_control` e a leitura custa uma fração da entrada; na OpenAI e no Gemini há cache automático de prefixo em vários modelos. Mantenha o prefixo estável: data ou id do usuário no começo do prompt quebra o cache. O inventário avisa SDK de IA sem sinal de cache no código.
3. **Batch** [IA-BATCH]. 50% de desconto nas três empresas para o que não precisa de resposta na hora (relatório noturno, classificação em lote). Entrega em até 24 h.
4. **Modelo menor** [IA-MODELO]. Classificação, extração e chat simples raramente precisam do maior. Teste num conjunto de exemplos reais antes de trocar.
5. **Limitar saída.** Saída custa várias vezes a entrada. Teto de tokens de saída e resposta curta pedida no prompt.
6. **Não chamar.** Cachear resposta igual no seu servidor, debounce no app, não gerar o que o usuário não abre.

## Cuidados
- Contexto longo pode ter preço maior (o CSV marca a faixa).
- Residência de dado ou região dedicada pode ter acréscimo: confira na página do fornecedor.
- Trocar modelo muda qualidade: quem decide é o dono, com exemplo lado a lado.
